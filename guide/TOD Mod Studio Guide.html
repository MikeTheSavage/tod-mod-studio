TOD Mod Studio

A level editor and mod manager for Total Overdose (2005). This guide explains, in plain words, what it does and how to use it.

1What it is

TOD Mod Studio lets you change Total Overdose's levels and game values without any other software. You can:

  • look around every level in 3D, with the game's real models and textures;
  • move, add and remove things in a level: pickups, weapons, enemies, vehicles, invisible walls, trigger boxes;
  • change numbers the game uses, such as weapon damage, clip sizes and car handling;
  • put your changes into the game with one click, and take them out again with one click;
  • share your mod with friends as a small file.

You need your own installed copy of Total Overdose (for example the GOG version). The app does not include any of the game's files.

2How it works

1. ReadThe app reads your installed game.
2. CacheIt copies what it needs into a cache on your PC, once.
3. EditYou change levels and values in the app.
4. BuildIt checks your changes and builds one mod file.
5. PlayThe game loads that file first, so your changes win.

The game's own files are never changed. Your mod lives in one extra file, todms_mods.zip, next to the game. The app adds that file to the game's list of files to load (in configpc.txt) and keeps a backup of that list. Removing your mods deletes the extra file and restores the list, and the game is exactly as it was.

Before anything is written, the app checks every change: the parts you did not touch must stay identical, nothing may point at something that does not exist, and the game's limits must be respected. If a check fails, nothing is installed and the app tells you what is wrong.

3Installing

  1. Run TODModStudio-Setup.exe. You do not need administrator rights.
  2. Keep the suggested folder or pick another one, choose your shortcuts, and click Install.
  3. Start it from the Start menu: TOD Mod Studio. This guide is there too: TOD Mod Studio Guide.
Windows may show "Windows protected your PC" because the installer is not signed by a company. Click More info, then Run anyway.

The app's window needs the Microsoft Edge WebView2 Runtime. Windows 10 and 11 normally have it already. If Setup says it is missing, install it from Microsoft's website first.

To uninstall: Windows Settings → Apps → Installed apps → TOD Mod Studio → Uninstall. Your mods stay in your library unless you tick the box to delete them too. Remove your mods from the game first (see section 7) if you want the game back to normal.

To update: run a newer Setup. It replaces the program and keeps your mods and settings.

4The first start

  1. Pick your Total Overdose folder: the one that contains TOD.exe and blocks.naz. For GOG that is usually C:\GOG Games\Total Overdose.
  2. The app checks the game and then copies the levels into its cache. This takes a few minutes and a few hundred MB of disk space. It only happens once.
  3. If you have the TOD HD graphics mod installed, the app notices and builds your mods on top of it.

5Editing a level

Open a level

Go to the Level editor tab. Pick a map, then a section of that map. If you also want the mission's enemies, pickups and vehicles, pick one or more missions. Click Open.

Move around

Change things

  1. Click an object in the 3D view or in the Objects list.
  2. Drag the arrows to move it. G moves, R rotates, T resizes boxes.
  3. The panel on the right shows its position, its type (which pickup, weapon or vehicle) and more. Type new values there if you want exact numbers.
  4. Add puts a new object in the middle of the view: a pickup, weapon, enemy, vehicle, trigger box, invisible wall, navigation blocker or route point.
  5. Duplicate (Ctrl+D) copies the selected object. Delete removes it.
  6. Made a mistake? Ctrl+Z undoes, Ctrl+Y redoes.

Layers hides or shows kinds of objects, the level's models and its collision (the invisible shapes you bump into, coloured by type).

Check tests your changes without installing anything and lists any problems, for example too many objects in a section or too many drivable cars in one place (the game allows 4 at once).

Some sections cannot take new objects (the app tells you which). New walls for those go into the map's shared layer instead, which is loaded with every section of that map.

6Changing game values

The Game data tab changes numbers the game keeps in its data files:

  • Weapons: damage, clip size, fire rate, range, ammo;
  • Vehicles: handling, health, cameras, traffic;
  • Moves and slow motion: power-up limits, stamina costs, combo rewards;
  • Camera: where the camera sits behind you and in cars, and how far you can see.

Your changes belong to the mod you are working on. A few things (such as field of view) are built into the game's program itself; the app lists those but cannot change them.

7Putting your mod in the game

  1. Click Save mod to keep it in your library.
  2. Go to the Mods tab. Tick the mods you want. When two mods change the same value, the one lower in the list wins.
  3. Close the game, then click Install enabled mods into the game.
  4. Start Total Overdose and play.

To go back to the normal game: close the game and click Remove all mods.

8Sharing mods

  • Share saves your mod as a .todmod file. It is small because it is a list of your changes (a recipe), not a copy of the game's files.
  • Your friend uses Import in their TOD Mod Studio. Their copy builds the mod from their own game when they install it.
  • Mods made with the project's Unreal level editor plugin also import here.

10Your saved games

Total Overdose saves remember objects by the order they were created. To keep your old saves working, the app:

  • adds new objects after the existing ones, never in between;
  • by default does not truly delete objects. It "retires" them: they move far below the world with their collision off, so you never see them. You can change this in Settings, but truly deleting can break saves made in that section, and the checker will warn you.

13Adding a new map and its teleport spots

Open New maps and click Create project, or paste the path to an existing map recipe JSON or build folder and click Import. A project is separate from your ordinary mod. Its files are kept in the newmaps folder beside your saved mods and settings.

  1. Give the package a name. Choose a map to copy and give the new map an unused name. The map name must have exactly the same number of letters as the original; the screen tells you the required length.
  2. Set Main arrival: where Ram appears inside the new map. Positions are in metres: x and z run along the ground; y is height. Check that there is ground under this point. Changing the map to copy does not move your spots.
  3. Under Entry spots, add a box, choose the existing map and section, and click the top view to place it. Type its height, facing and size. Walking into this invisible box loads the new map. The other boxes shown are the game's existing loading zones; avoid placing your new box across one of them.
  4. Add Named arrivals inside the new map if different entrances should lead to different places. Choose the destination in each entry box's Arrive at list. The inside view shows all your spots and their facing arrows. It does not draw the ground or buildings.
  5. Set the Return spot, including the existing map, section and named point Ram should return to. Imported recipes keep these names. The block containing that point must be correct so the checker can find it.
  6. Click Save project, then Check. Read each PASS, WARN or FAIL message. Check reads the recipe and destination names; Build also writes the map and checks its objects, collision and finished package. The output folder is shown when it finishes. A saved copy of the recipe is included in that folder.
  7. Close the game and click Install package. The app copies the package into the selected game folder and puts it first in the game's loading list. It backs up configpc.txt. If an installed mod or another map package changes the same part of the game, remove that one first. Uninstall package removes just this project's package and keeps the other archives in order. Save and rebuild after changing any spots.

An older map builder may support only one entry leading to the main arrival. The screen says when this applies; extra entries can be saved but cannot be built until the app includes the newer builder. Older build folders may also lack the original recipe: the app warns if only their spots were recovered. Import the original JSON to keep all walls, objects and other map contents.

14Adding your own missions

Making a mission

Open Mission templates. A mission project holds one or more missions that take place on a map of yours (a project from New maps) or in a part of an existing map such as Downtown.

  1. Click New project, or open a sample from the list: Mesa Compound shows all 17 kinds on one map (it uses all 17 mission slots), the yard sample is a short two-mission example.
  2. Under Maps for the missions add the map: one of your new maps, or a section of an existing map. Sections that cannot take a mission giver are greyed; hover to see why. For an existing section, give its walkable play area and ground height, and choose a shipped mission to start like.
  3. Under Add a mission, pick a kind. Each card says what the player does and what the map needs. Then place things: select the mission, click Place next to a point or area and click the top view (north is up). The yellow box is the mission giver: the player steps into it and presses the use key to be offered the mission.
  4. Change the numbers in the form. Every setting says what it does and its allowed range; "use the default" undoes a change.
  5. Check lists what to fix, in plain words (a giver on a building, a pass score nobody can earn, boxes too close together). Then Build (about a minute) and, with the game closed, Install.

Gameplay+

If the Gameplay+ mod is installed, the app builds the missions on top of it, so Gameplay+'s own changes stay in effect. Install Gameplay+ first, then build and install your missions.

Slots. A game can have 17 new missions in total. The page shows how many are left. All your installed mission projects are built together into one package, todms_missions.zip, so installing a second project rebuilds the first one with it. The game can load 8 archive files; the app refuses an install that would go over that. If a new map you use here was installed from the New maps tab, installing the missions replaces that package (the map is part of the missions package).

Old saves. A save made before you installed the missions does not know them: pressing the use key at a new mission giver would close the game. Open Test save, Update a save for new missions, pick the save and make an updated copy. It never changes your save and never runs by itself; installing the copy backs up the slot it replaces. A new game, or a save made after the install, needs nothing.

Givers in an existing section (Downtown and so on). A giver box placed in a section the game already has needs one more thing in an old save: its script thread. The save update adds it when the save holds that section. A save that does not hold the section (for example one made right at the end of the game, or at the start of a mission) loads the section fresh and the box stays silent until the section is loaded again: start or finish any mission, or walk through any map loader and come back. A new game loads sections that way, so it needs nothing. Placing a goal zone on top of the giver box (the Ghost run) is refused: you accept standing in the box, and a zone only counts when you walk into it.
