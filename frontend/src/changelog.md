## 1.2.0
- Enemies: pick the body of each enemy you add, plus its look, behaviour, side and weapon. A build adds any body a level lacks, and mission templates can set the enemy body.
- Names instead of numbers for characters, vehicles, factions and weapons.
- Driving presets in Tune > Vehicles: Drift, Grip, Heavy and Vanilla, for one vehicle, a group or every car. Save and share your own.
- Vehicles from Chili Con Carnage: import them from your own copy of the game onto TOD cars.
- Blender add-on: send a model straight from Blender 2.79 to 5.x (Settings > Blender, off by default).
- Model import: OBJ, GLB and glTF files from older Blender versions load, with clearer messages when a file cannot be read.
- Fixes: the Limits strip no longer covers menus, the mission graph pans and zooms properly, and dragging the camera no longer selects or moves things (Shift+drag draws a selection box).

## 1.1.0
- New maps: build a map from scratch with terrain, paint, roads, edges, scatter, look, blockout pieces, sections and a minimap.
- Import a whole city or district from a 3D file as a new map, with lighting baked in.
- Mission templates: 17 mission types you can place in your own maps, with entrances and a way back.
- The Limits strip and Problems list now follow every new map.
- Fixes: the Map view stays usable in a narrow window; Ready lists only a project's own rows.
- A mission giver box can no longer hold a place where the player lands (entrance, map arrival or spot): the check refuses it.

## 1.0.11
- New Help window: the guide with search, a glossary, lessons and examples. Open it with the ? button or F1.
- Three short lessons run inside the editor, and a first walkthrough is offered after setup.
- Three small example projects: a level tweak, a tuning tweak and a race mission.
- Beginner mode hides the rarely used screens. Switch it in Settings or in Help.
- New accessibility settings: UI scale, text size, high contrast, colour-blind safe colours and reduced motion.
- The theme follows Windows by default.
- Every word of the interface is now in one language file, ready for community translations.

## 1.0.10
- A new look for the whole app, with the Limits and Problems strip, versions and autosave.
- Test in game, the Debug area, model import, textures and the asset catalogue.
- Controller support, Tune previews and the Playground.
